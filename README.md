# portifolio

Portfólio pessoal em HTML, CSS e JavaScript puros — sem build. Abra `index.html` no navegador.

## Estrutura

- `index.html` — conteúdo (os trechos entre `[colchetes]` são placeholders para preencher)
- `styles.css` — tema escuro/claro, layout com barra lateral e versão mobile
- `script.js` — navegação ativa, menu mobile, animações ao rolar, hora local, copiar e-mail e troca de tema

## Publicar

Ative o GitHub Pages em *Settings → Pages* apontando para a branch principal.
